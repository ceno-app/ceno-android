В этой версии:
- Переработана пользовательская навигация с помощью кнопки «Назад» с использованием OnBackPressedDispatcher
- Обновлен компонент BrowserActivity для запуска в режиме singleInstance
- Заменен флаг FLAG_ACTIVITY_NEW_TASK на FLAG_ACTIVITY_CLEAR_TASK
- Обновлен плагин Android Gradle до версии 8.13.0
- Добавлена возможность закреплять сайты в кэше
- Уменьшено количество записей в журнале по умолчанию в релизных сборках
- Удалена страница ожидания
- Компоненты Android обновлены до версии v146.0.1
- Добавлена настройка, позволяющая скрыть ленту бесплатных медиаресурсов
- Ouinet обновлен до версии v1.6.1
- Добавлена возможность включения/выключения DNS-over-HTTPS в качестве резолвера по умолчанию
